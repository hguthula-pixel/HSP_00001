# Background music

Place the owner-supplied track here as `market-theme.mp3`.

- It starts only after the visitor presses "Enter the market", at 25% volume with a 3-second fade-in, and loops.
- If the file is missing or can't play, the market keeps working silently and Help says why.
- Record the track's title, author and license in `docs/ASSETS.md` before publishing.
